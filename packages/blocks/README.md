# @crumza/blocks

Four MIT-licensed React website blocks: HeroBlock, FeatureGrid, PricingBlock and FAQBlock.

Local alpha, not yet published. Requires React 19.2 and @crumza/ui.

Import Tailwind, @crumza/ui/styles.css, then @crumza/blocks/styles.css. Scope colors and radius with Theme from @crumza/ui. The blocks remain opaque for readable content.

Each block accepts native section attributes. Provide real links/actions; no checkout or backend is bundled. FAQ is native details/summary and works without hydration.

See the public website's /docs/blocks page for typed prop descriptions and examples.
